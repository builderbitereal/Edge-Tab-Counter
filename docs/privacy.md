# Privacy Policy

Effective date: 2026-05-09

Edge Tab Counter is built by BuilderBite.

## Data Collection

Edge Tab Counter does not collect personal data, browsing history, analytics, telemetry, or usage events.

## Local Browser Access

The extension uses Microsoft Edge extension APIs to read the tabs in the current browser window. This is required to calculate tab order and display tab numbers.

The extension may read tab titles and URLs locally so the popup can show a readable tab list. This information stays inside the browser and is not sent to BuilderBite or any third-party server.

## Network Requests

Edge Tab Counter does not make remote network requests.
