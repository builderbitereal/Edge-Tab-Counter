Edge Tab Counter

Instant tab numbering for Microsoft Edge without editing the page title.

How It Works

The extension watches tab create, close, move, activate, and reload events. Supported web pages receive a large numbered favicon, and the extension toolbar icon mirrors the active tab number as a protected-page fallback.

Privacy

Edge Tab Counter does not collect, sell, upload, or track browsing data. URLs and titles are read only inside your browser so the popup can show the current window list.

Limitations

Microsoft Edge does not allow extensions to draw custom labels directly inside protected browser pages or the native tab strip. On blocked pages, the generated toolbar icon still provides the tab number.
