Edge Tab Counter

Instant tab numbering for Microsoft Edge titles and toolbar icons.

How It Works

The extension watches tab create, close, move, activate, and reload events. Supported pages receive a tab title prefix, and every active tab shows the number through the extension icon and badge.

Privacy

Edge Tab Counter does not collect, sell, upload, or track browsing data. URLs and titles are read only inside your browser so the popup can show the current window list.

Limitations

Microsoft Edge blocks title edits on internal browser pages. Those pages still use the independent extension icon and badge number.
