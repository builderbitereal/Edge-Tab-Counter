# Contributing

Thank you for improving Edge Tab Counter.

## Local Development

1. Clone the repository.
2. Open `edge://extensions/` in Microsoft Edge.
3. Enable `Developer mode`.
4. Load the project folder as an unpacked extension.
5. Make changes and click `Reload` on the extension card.

## Pull Requests

- Keep the extension title-safe. Do not write to `document.title`.
- Keep user data local. Do not add analytics or remote tracking.
- Test tab create, close, move, reload, and multi-window behavior.
- Update README or docs when behavior changes.
